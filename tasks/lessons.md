# Lessons — CRIADOR SPRITES

- **Não prometer "1 imagem 2D → folha completa".** É impossível com qualidade/consistência
  de MMO. O caminho honesto é 3D pré-renderizado. Explicar o porquê ao usuário.
- **Concept para 3D = vista de FRENTE, pose A, mãos vazias, SEM armas/acessórios soltos,
  fundo branco.** NÃO pedir "isométrico" à IA (o ângulo iso vem do render 3D).
- **Armas/acessórios finos ou pendurados quebram a reconstrução 3D** — sempre peças separadas.
- **Usuário é dev/analista, não desenhista** — priorizar automação e um comando único simples.
- **No isométrico a cabeça "encolhe" (foreshortening)** — normal; chibi (cabeça grande) lê melhor.
